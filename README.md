# 💻 FlexBlog

Projeto de um site responsivo desenvolvido para praticar **Flexbox e conceitos de CSS**.

O site possui seções de apresentação, produtos, planos de preços, características e newsletter.

## 🚀 Tecnologias utilizadas

* HTML
* CSS
* Flexbox

📚 Projeto desenvolvido para praticar conceitos de desenvolvimento web e layouts responsivos.
